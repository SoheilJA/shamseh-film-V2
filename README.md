# گروه سینمایی شمسه فیلم — Luminous Archive

بازطراحی کامل فرانت‌اند وب‌سایت گروه سینمایی شمسه فیلم (مشهد، ایران) با تم روشن «آرشیوی نورانی»،
رشدیافته از نشانِ خودِ گروه: قاب برگِ فیروزه‌ای و امضای طلایی.

![Shamseh Film](public/images/logo-full.png)

## پشتهٔ فناوری

- **Vite 8** — ابزار توسعه و ساخت
- **Tailwind CSS 4** (`@theme` tokens) — سیستم طراحی
- **JavaScript ES2022+ ماژولار** — بدون React / Vue / Angular
- **GSAP + ScrollTrigger** — موشن «نور و کاغذ»
- **Lucide** — آیکون‌ها (فقط ۱۸ آیکونِ استفاده‌شده در باندل)
- بدون بک‌اند، بدون دیتابیس؛ همهٔ محتوا از `src/data/*.js`

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی در dist/
npm run preview  # پیش‌نمایش خروجی build
```

## صفحات

| مسیر | توضیح |
|---|---|
| `/` | صفحهٔ اصلی — هیرو، آثار منتخب، معرفی، دسته‌ها، اخبار، گالری، اختتام |
| `/productions` | آرشیو با فیلتر دسته، جستجو و شمارنده |
| `/productions/:slug` | صفحهٔ اختصاصی هر اثر — خلاصه، پیش‌نمایش ویدیو، عوامل کامل، گالری، آثار مرتبط، قبلی/بعدی |
| `/news` | آرشیو اخبار با جستجو و «بیشتر» |
| `/news/:slug` | صفحهٔ مقاله با نوار پیشرفت مطالعه و اشتراک‌گذاری |
| `/about` | معرفی گروه (فقط بر پایهٔ محتوای واقعی) |
| `/gallery` | گالری masonry با فیلتر و لایت‌باکس |
| `/contact` | تماس با نقشه، تماس مستقیم و پیوندهای مرتبط |

## حفظ محتوا

تمام محتوای معنادار shamsehfilm.ir از WordPress REST API استخراج و در این پروژه حفظ شده است:
عنوان و خلاصهٔ هر ۴۳ اثر، عوامل کامل (۱۱۰۰+ اعتبار)، متن کامل ۱۱ خبر، ۸ گالری تصویر،
اطلاعات تماس و ۷ پیوند مرتبط. هیچ داده‌ای جعل نشده؛ اثری که ویدیو ندارد، ویدیو نشان نمی‌دهد.

## دسترس‌پذیری

- `lang="fa"` و `dir="rtl"`، کنتراست AA (فیروزهٔ عمیق #0C7A80 برای متن)
- فوکوس‌رینگ ۲px، ناوبری کیبورد کامل (لایت‌باکس، جستجو، منو)
- `prefers-reduced-motion` پشتیبانی می‌شود
- فونت‌ها خودمیزبانی با `font-display: swap`، تصاویر WebP + lazy loading
